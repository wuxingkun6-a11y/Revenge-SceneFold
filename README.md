# SceneFold v0.1.3

修复候选版，需在 Revenge / Discord 安卓客户端验证。

## 修复

- 恢复消息前，把 MessageStore 的 messageSnapshots / messageReference 等内部字段转换为 Flux 接收的 message_snapshots / message_reference，兼容 v0.1.2 保存的记录。
- 合并本地删除和插入操作，取消过期的待执行替换，避免快速展开后又被旧任务折叠。
- 停用插件时取消待执行任务并恢复已加载消息。
- 菜单缺少 channel_id 时，从菜单频道信息或唯一匹配的旧记录补足。
- 收到完整服务器消息时更新原文备份；不把摘要替身当作原文备份。
- 原文备份缺失时保留记录并尝试重载，不再直接提示“已展开原文”。

## 更新（保留现有记录）

在原插件托管仓库覆盖 index.js、manifest.json、README.md，然后使用客户端提供的插件更新功能拉取新版并完全重启 Discord。
不要先卸载插件或清空插件数据。单纯开关插件是否重新下载取决于客户端，不保证触发更新。

沿用安装地址：
https://raw.githubusercontent.com/wuxingkun6-a11y/Revenge-SceneFold/main/

此压缩包没有自动上传到该地址。必须先更新托管文件，否则仍然会下载旧版。

## 手机验证

1. 长按之前折叠的小剧场，确认出现“展开已玩小剧场”。
2. 展开后核对转发正文、图片和引用；退出再进入帖子检查。
3. 重新折叠、展开、编辑摘要、取消标记各测试一次。
4. 快速收起再展开，确认不会自动变回摘要。
5. 停用插件，确认已加载的消息恢复。

若旧版已将原文备份保存为摘要，插件会取消折叠并尝试重新获取；必要时完全重启 Discord，再进入帖子。服务器原消息必须仍然存在且可访问。

## 测试及限制

未连接真实安卓设备，不能保证 Discord 347.12 或其他版本的内部消息结构及长按菜单兼容。仍使用旧版的本地 Flux 替换方案，未改为纯渲染层折叠。
