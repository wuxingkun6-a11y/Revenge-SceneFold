# SceneFold v0.1.4 — 服务器原文恢复候选版

v0.1.3 的手机测试仍未恢复原文。此版不再把旧的本地备份作为手动展开/取消标记的来源。

## 改动

- 展开/取消标记时，使用 Discord 客户端已有的 HTTP 模块读取该频道目标消息附近的消息，按完整频道 ID 和消息 ID 精确匹配原文。
- 只发 GET 请求，不修改服务器消息，不提取或保存账号 token。
- 原文回填本机缓存后检查正文、转发内容和附件数量；必要时调用 Discord 自身的消息加载器再试。
- 失败时保持取消折叠状态、保留重试入口和记录，不提前报告恢复成功或删除记录。
- 旧版已删除记录却留下摘要的消息，可长按选择“从服务器恢复原文”。
- 异步请求完成前重新折叠或停用插件，不再让旧请求覆盖用户的新操作。
- 加载提示、恢复菜单明确标出 v0.1.4，便于确认更新是否真正生效。

## 安装更新

覆盖原托管仓库的 index.js、manifest.json、README.md，使用插件更新功能拉取，并完全关闭后重新启动 Discord。保留插件本地数据，不要先卸载。

本文件包未自动上传到托管仓库。原地址只有在仓库更新后才会返回新代码：
https://raw.githubusercontent.com/wuxingkun6-a11y/Revenge-SceneFold/main/

## 手机验证

1. 启动时应看到“SceneFold 0.1.4 已加载”。
2. 长按旧摘要，应看到“从服务器恢复原文 · v0.1.4”。没有版本号说明仍在运行旧代码。
3. 点击恢复。此步骤需要网络及该频道的读取权限。
4. 检查原文及图片。如果显示失败，将提示文字或截图反馈。即便提示缓存已写回，仍需目视确认手机界面；必要时重进帖子。
5. 再次折叠、展开、取消标记各测试一次。

## 已验证与限制

node --check index.js
node tests/regression.cjs

模拟测试覆盖损坏备份下的服务器恢复、转发附件/引用、取消标记、无记录摘要恢复、HTTP 拒绝、找不到消息、响应格式异常、本机缓存拒绝替换、原生加载器回退、重新折叠/停用时的异步竞争。

未连接真实安卓客户端。实际渲染兼容性仍未验证；本机缓存检查不能证明屏幕已刷新。此版仍沿用本地消息替换架构，不是纯渲染层折叠。服务器原消息已删除或无权限时无法从服务器恢复。
